## Quick Reference

| Variant | Best for | File format | Recommended file |
|---|---|---|---|
| Main logo large | Hero images, splash screens, large print | PNG/SVG | `01-main-logo-stor_4x.png` |
| Horizontal small | PDF headers, document footers, email | PNG/SVG | `04b-main-logo-horisontell-liten-ren_4x.png` |
| Favicon (red) | Browser tabs, app icons | PNG/ICO/SVG | `05-favicon-rod.svg` |
| Favicon (dark) | Dark backgrounds | PNG/ICO/SVG | `06-favicon-mork.svg` |

<Note>
  All files come from the approved `vvb-logo-ratt-v4` asset set. Do not use files from earlier versions.
</Note>
