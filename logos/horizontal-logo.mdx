The horizontal VVB logo is the recommended mark for document headers, PDF footers, and compact layouts. It presents the VVB identity in a wide-format, space-efficient form.

## Available Files

| File | Format | Use case |
|---|---|---|
| `04b-main-logo-horisontell-liten-ren.svg` | SVG | Scalable, digital headers |
| `04b-main-logo-horisontell-liten-ren_4x.png` | PNG 4× | PDF / high-res documents |

## PDF Integration

<Steps>
  <Step title="Set the image source">
    Use the raw GitHub PNG URL above as the `src` in your PDF template's image tag.
  </Step>
  <Step title="Set the image width">
    Set image width to fit your document header area (recommended: ~200–300px wide).
  </Step>
  <Step title="Preserve clear space">
    Ensure adequate white space around the logo — do not crop or clip the mark.
  </Step>
</Steps>

<Note>
  This is the officially recommended file for all PDF and document headers. See the README for the authoritative guidance.
</Note>
