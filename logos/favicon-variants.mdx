The VVB favicon variants are icon-only logo marks designed for small-format use. Two variants are available: red (for standard/light backgrounds) and dark (for dark backgrounds or dark-mode contexts).

## Variants

### Red Variant (`05-favicon-rod`)

Available files: `.svg`, `.png`

Use for browser favicons, standard app icons, and light backgrounds.

Raw URL for SVG:

```
https://raw.githubusercontent.com/vvb-1/vvb-brand-assets/main/assets/vvb-logo-ratt-v4/logos/05-favicon-rod.svg
```

### Dark Variant (`06-favicon-mork`)

Available files: `.svg`, `.png`

Use for dark-mode contexts and dark-background placements.

Raw URL for SVG:

```
https://raw.githubusercontent.com/vvb-1/vvb-brand-assets/main/assets/vvb-logo-ratt-v4/logos/06-favicon-mork.svg
```

## When to Use Each Variant

| Context | Recommended variant |
|---|---|
| Light background | Red (`05-favicon-rod`) |
| Dark background | Dark (`06-favicon-mork`) |
| Browser favicon (standard) | Red |
| PWA/app icon (dark theme) | Dark |

<Info>
  For favicon use in websites and apps, see the Favicons section which provides ready-to-use multi-resolution PNG bundles and web manifest files.
</Info>
