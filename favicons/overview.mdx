The VVB favicon bundle provides all the icon sizes and formats needed to represent Vi Vet Bil AB correctly across browsers, operating systems, and devices. The bundle includes both a red and a dark variant.

## What's included

| File | Size | Use |
|---|---|---|
| `favicon.ico` | Multi-size | Universal browser fallback |
| `favicon-16x16.png` | 16×16px | Browser tab (small) |
| `favicon-32x32.png` | 32×32px | Browser tab (standard) |
| `apple-touch-icon.png` | 180×180px | iOS home screen |
| `android-chrome-192x192.png` | 192×192px | Android / PWA |
| `android-chrome-512x512.png` | 512×512px | Android / PWA high-res |
| `site.webmanifest` | — | Web app manifest |

## Variant bundles

There are two icon mark variants available in the bundle:

- **`05-favicon-rod-*`** — Red variant, sizes 16px to 1024px
- **`06-favicon-mork-*`** — Dark variant, sizes 16px to 1024px

The standard `favicon.ico`, `apple-touch-icon.png`, and `android-chrome-*` files use the dark variant.
