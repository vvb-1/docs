This page lists every file in the VVB favicon bundle with its dimensions, size, and SHA-256 checksum. Use checksums to verify you have an unmodified, officially approved asset.

## Integrity Verification

<Info>
  The official checksums are recorded in `manifest.json`, included in the VVB brand asset download. If the SHA-256 of your downloaded file does not match, do not use it — re-download from the official source.
</Info>

## Verifying a file

Run the appropriate command for your operating system, then compare the output against the corresponding value in `manifest.json`:

```bash
# macOS
shasum -a 256 favicon.ico

# Linux
sha256sum favicon.ico

# PowerShell (Windows)
Get-FileHash favicon.ico -Algorithm SHA256
```

Compare the output against the value in `manifest.json`.
