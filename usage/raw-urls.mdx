Some tools — PDF renderers, email clients, no-code platforms, and third-party integrations — require publicly accessible image URLs rather than local file paths. Use these raw GitHub URLs to reference VVB brand assets directly without hosting them yourself.

<Note>
  These URLs resolve directly from the GitHub repository. They are suitable for documents, prototypes, and external tools. For high-traffic production web applications, self-host the assets instead.
</Note>

## Using a URL in HTML

Paste any URL from the lists above directly into an `<img>` tag. The example below uses the recommended horizontal logo:

```html
<img
  src="https://raw.githubusercontent.com/vvb-1/vvb-brand-assets/main/assets/vvb-logo-ratt-v4/logos/04b-main-logo-horisontell-liten-ren_4x.png"
  alt="Vi Vet Bil AB"
  width="200"
/>
```

<Warning>
  Do not hotlink these URLs in production web applications with significant traffic. GitHub's raw CDN is not intended for high-volume image serving. Download and self-host the files for production use.
</Warning>
